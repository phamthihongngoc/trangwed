## Demo local

- Trang chu: ngoc.html
- Chay local: http://localhost:5500/ngoc.html

- CSS3

## Cach chay du an tren may tinh

### Cach 1: dung Python

1. Mo PowerShell tai thu muc du an:

	 ```powershell
	 cd D:\Ngoc\Du_an\trangwed.github.io
	 ```

2. Chay web server local:

	 ```powershell
	 python -m http.server 5500
	 ```

3. Mo trinh duyet:

	 ```
	 http://localhost:5500/ngoc.html
	 ```

4. Dung server: nhan `Ctrl + C`

### Cach 2: dung Python trong .venv

```powershell
D:\Ngoc\Du_an\trangwed.github.io\.venv\Scripts\python.exe -m http.server 5500
```
